# Simulação de Sinistros em Seguros

Este projeto simula a ocorrência de sinistros em uma carteira de seguros utilizando conceitos básicos de probabilidade e programação em Python.

## Objetivo
Estimar o número de sinistros e o custo total para uma seguradora com base em uma probabilidade de ocorrência de acidentes.

## Tecnologias utilizadas
- Python
- Biblioteca random

## Como funciona
- Cada cliente possui uma probabilidade de sofrer um acidente
- Quando ocorre um sinistro, um custo aleatório é gerado
- O programa calcula:
  - Número total de sinistros
  - Custo total
  - Custo médio

## Exemplo de uso
Execute o arquivo `simulacao.py` em um ambiente Python.
